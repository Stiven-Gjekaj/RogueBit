# Support

- **Something is broken.** Open an
  [issue](https://github.com/Stiven-Gjekaj/RogueBit/issues/new/choose) and use
  the bug report template. Include the seed. A seed replays a run exactly, so it
  is usually all that is needed to see the same thing you saw.
- **You want something added.** Open an issue with the feature request template.
- **You want to help.** Read [CONTRIBUTING.md](CONTRIBUTING.md) first.

This is a personal project, so a reply may take a while.
