# Security

RogueBit is a single player game. It opens no ports, makes no network
connection, and reads no file it did not write.

If you find something that behaves otherwise, please report it privately through
GitHub's [security advisories](https://github.com/Stiven-Gjekaj/RogueBit/security/advisories/new)
rather than in a public issue.

Only the most recent release is supported.
